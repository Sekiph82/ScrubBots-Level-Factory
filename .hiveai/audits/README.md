# Independent Strict Audits

This directory stores ChatGPT-authored independent strict audits.

Codex must not create or edit audit files.

For every cycle, the matching audit must use the exact same H1 as its prompt and Codex log.

Example:

`# PAG-M00-C001 — Repository Bootstrap & Governance`

Immediately below the H1:

`Document role: CHATGPT INDEPENDENT STRICT AUDIT`

Historical PASS, CONDITIONAL, and FAIL audits remain immutable. Required corrections use a new remediation cycle rather than rewriting the prior audit.
