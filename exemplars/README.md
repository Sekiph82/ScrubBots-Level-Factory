# Production exemplar inbox

The production WFC exemplar registry is intentionally empty in M05. This directory is an owner-controlled inbox; inbox items are never auto-approved, and provenance plus the complete logical-contract validation are mandatory before use. Files are not loaded by the runtime. Only a future owner-approved review process may populate it.

Upstream or external WFC sample images are forbidden as SCRUBBOTS owner exemplars. No owner-approved exemplar ships in M05.

The synthetic logical exemplars used by tests live under `tests/fixtures/wfc/` and are not production assets.
